## Групповой проект

### Команда

1. Проект выполняет в команде в составе от 3-х до 5-ти человек. В качестве участников могут быть обучающиеся 1 курса любого направления (ИВТ, ПИ, КБ);
2. Команда выбирает лидера и название. Название может быть любым, главное, чтобы не повторялось у разных команд. Оно ни на что не влияет и нужно просто для удобства;
3. Лидер регистрирует команду [[здесь](https://forms.yandex.ru/u/6afbfb0f974ab2959afd9fc0)]. В дальнейшем состав команды может быть изменён по решению команды. Например, если участник не выполняет свою часть работы, его можно исключить. О всех перестановках в команде нужно сообщить до даты защиты иначе эти сведения не будут учтены при выставлении оценки.
